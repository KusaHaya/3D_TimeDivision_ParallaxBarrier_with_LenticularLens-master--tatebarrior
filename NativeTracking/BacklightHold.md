# バックライトの停止・位相保持

PCの main.cpp は t で現在の表示位相を保持し、210〜213を送ります。
Arduinoには更新した ProjectPB/Arduino.txt のスケッチを書き込んでください。
PCのリビルドだけではArduinoのプログラムは更新されません。

- t: 現在の液晶位相と対応する上下LEDペアを保持。LEDは連続点灯。
- 停止中の q/w/e/r: それぞれ位相0/1/2/3へ液晶と上下LEDペアを切替。
- 再度 t: 位相0から時分割を再開。
- 200〜203: PCの1提示フレームにつき指定した1位相をパルス点灯。
- 210〜213: 指定ペアを連続点灯し、新しい保持または再開コマンドまで維持。
- 20: 消灯・位相リセット。12: 時分割再開。

Arduino IDEでスケッチとして保存し、接続ボードとCOMポートを選んで書き込みます。
書き込み中はProjectPB、Unity、シリアルモニター等を終了してCOMポートを解放してください。
OUTPUT_PINSは既存の {9,10,11,12,4,5,6,7} を維持しています。実機配線と合わせてください。

NativeTracking/test_backlight_hold.cpp はArduino APIのスタブで全4位相の保持、
無通信での保持、停止中の時分割コマンド無視、再開と1フレーム1位相を検証します。
g++ -std=c++11 NativeTracking/test_backlight_hold.cpp -o test_backlight_hold
でビルドして実行できます。実機タイミング・輝度・物理同期は未検証です。
