# バリアの表示調整

静止画・動画の丸め境界は共通で、起動時は0.80です。
位置・周期の既定値と4時分割の処理は維持しています。

| 操作 | 動作 |
|---|---|
| o / Shift+o | 表示位置 SHIFT を +1 / -1 |
| [ または a / ] | haba を +1 / -1 |
| f / Shift+f | 傾きを -0.02 / +0.02 |
| u / Shift+u | 丸め境界を -0.05 / +0.05 |
| t | 時分割停止・再開 |
| q / w / e / r | 停止中の位相選択 |

幅・位置・丸め境界は停止中も操作直後に更新し、[ALIGN]で現在値を表示します。
丸め境界は0.05〜1.00、habaは2〜100000に制限します。
境界0.80では1.8未満→1、1.8以上→2となります。
負の補正量は絶対値に同じ基準を適用して符号を戻します。
1.00では通常のゼロ方向への整数化に相当します。

トラッキングOFF中や追跡停止時は表示の調整値を保持します。
追跡中に幅を手動調整した場合も、追跡の基準幅へ差分を反映します。
これらの値はメモリ上の設定です。再起動後の保存・復元は未実装です。

更新時はC++を再ビルドし、実行時に読むinterleave.fragと
sbs_interleave.fragも同時に更新してください。
シェーダーだけ更新して古い実行ファイルを使う場合、境界は0.80のままで
新しいキー操作は使えません。

今回の変更は調整の即時反映と比較を目的とします。
クロストーク低減量は実機で測定してください。
