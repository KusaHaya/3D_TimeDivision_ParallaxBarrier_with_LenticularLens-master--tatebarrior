# 全面消灯で比較するArduino版

- 通常の上下分割版: `Arduino.txt`
- 全面消灯比較版: `Arduino_FullBlanking.txt`

比較版だけをArduino IDEの新しいスケッチに貼り付けて書き込んでください。
2つのコードを同じスケッチへ連結しないでください。PC側の変更は不要です。

## 動作（PCからフレーム指令を受信した時刻が0）

| 設定 | 全面消灯 | 新しい位相の上下を同時点灯 | 再び全面消灯 |
| --- | --- | --- | --- |
| 144 Hz | 0～3750 µs | 3750～6250 µs | 6250 µs以降 |
| 120 Hz | 0～4500 µs | 4500～7500 µs | 7500 µs以降 |

常に8出力を消灯する版ではなく、画面切替中に全面消灯する比較用です。
指令受信後は前の位相を再点灯しません。次の指令が早く来た場合も、まず全面消灯します。
フレーム指令の受信と実際の液晶の走査開始には差があり得ます。これらの時刻は液晶応答終了の実測値ではありません。

## クロストークの最小値の確認

1. `REFRESH_RATE` を実際の表示設定に合わせます（既定144）。
2. 全面消灯比較版を書き込み、通常の時分割動作中に測定します。
3. 同じ測定位置・幾何条件・LED電流で、左右の白黒入替と両眼黒を測定します。
4. `FULL_ON_US` を遅らせて再測定します。例えば144 Hzなら、
   `#define FULL_ON_US DEFAULT_FULL_ON_US` を
   `#define FULL_ON_US 4250UL`、次に `4750UL` に変更します。
   点灯終了は6250 µsのままなので、点灯時間は順に2500、2000、1500 µsです。
   開始時刻は0より大きく、点灯終了より前に設定してください。
5. 各条件で `(漏れ輝度－両眼黒輝度)/(目的画像輝度－両眼黒輝度)` を比較します。
   点灯時間を短くすると平均輝度も下がるため、目的画像輝度と漏れ輝度も併記してください。
   測定器の積分時間は時分割周期に対して十分長くし、各条件で一定にしてください。

`t`による停止時は従来どおり選択位相の上下を連続点灯し、`q/w/e/r`で固定位相を切り替えます。
停止中はこの全面消灯の時間制御を行わないため、時間同期の比較はRUN中に行ってください。
起動前・通常終了後の全点灯、単独出力の点灯、位相と配線の対応も従来どおりです。

元の上下分割版に戻すときは `Arduino.txt` を書き戻してください。
